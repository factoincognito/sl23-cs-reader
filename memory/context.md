# Session Context

**Purpose:** Reasoning and conversation context that does not fit
neatly into the structured memory files (`memory/project.md`,
`memory/decisions.md`). Read this alongside them, not instead of them.
Clead reads it at session start (`RULES.md`, L § 3) and keeps it as
Process P-9 § 1 (3) of the Rules in `rules/` says.

---

## How this project came to exist

Adam decided on 2026-10-29 that SL2/SL3 log analysis comes first, in its own repository, bootstrapped with the template's C# pack. The first purpose is to prove that the pack works; the analyser itself is secondary and should, if possible, be useful and not something Claude can do on a pasted file. His SL2/SL3 recordings are too large to pass to Claude, so a tool reads them and hands Claude a small report. The design was written in the product office before this repository existed and was approved on 2026-11-23.
